# Contributing

Use Windows and the prerequisites in the [README](README.md). Run `npm ci`, `npm run check`, and `npm test` before opening a pull request. For changes to desktop behavior, record the Windows version, display scale, and the steps you verified.

Describe the intended behavior and include screenshots for visible changes. Use test settings and sample data. Keep local paths, settings, logs, and generated binaries out of changes.

Keep provenance and license text with any vendored source, fonts, or other assets you add. Original contributions are made under the [project MIT license](LICENSE).
